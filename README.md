# 📝 Blog Generator using Llama-2 (Local LLM)

A Streamlit-based **AI Blog Generator** that uses a **locally hosted Llama-2 model (GGML)** via CTransformers.  
No API keys required — everything runs fully offline.

---

## 🚀 Features

- Generate blog posts from any topic  
- Choose writing style (Researchers, Students, AI Engineers, etc.)  
- Adjustable blog word count  
- Runs on a local Llama-2 model  
- Simple Streamlit UI  
- 100% private — offline model execution
